# Tour Rails

Tour Rails are specialized track blocks that enable automated tour vehicle systems.  
Combined with Tour Rail Triggers, they allow you to create immersive self-driving park tours, inspired by the iconic automated tour system from *Jurassic Park* (1993).

---

## Tour Rail

### Functionality
- **Type**: Track block
- **Purpose**: Creates pathways for automated tour vehicles
- **Placement**: Can be placed on the ground in any configuration
- **Compatible Vehicles**: [**Ford Explorer**]($content/vehicles/ford_explorer)
- **Connection**: Rails automatically connect to adjacent Tour Rail blocks

### Usage
1. Place Tour Rails on the ground to create your desired tour route
2. Rails will automatically connect to form a continuous path
3. Create curves, straightaways, and complex layouts
4. Place a compatible vehicle (Ford Explorer) on the rails
5. Use a **Wrench** on the vehicle to toggle automated tour mode
6. The vehicle will follow the rail path automatically

### Placement Tips
- Plan your route to showcase key exhibits and viewing points
- Tour Rails can be laid in straight lines, curves, and complex patterns
- Ensure the track forms a complete loop or has designated start/end points
- Consider terrain elevation when planning routes
- Leave space for creatures to be visible from the tour path

---

## Tour Rail Trigger

### Functionality
- **Type**: Special track block with trigger functionality
- **Purpose**: Controls vehicle behavior at specific points on the tour
- **Placement**: Placed on existing Tour Rail paths
- **Functions**: Speed control, stops, and waypoint markers

### Usage
1. Place a Tour Rail Trigger at any point along your Tour Rail path
2. The trigger replaces that section of rail while maintaining connectivity
3. Configure trigger settings (if applicable)
4. Vehicles automatically respond when passing over the trigger

### Trigger Functions
- **Speed Control**: Adjust vehicle speed at specific sections
- **Stop Points**: Create designated stops for viewing exhibits
- **Waypoints**: Mark important locations along the tour
- **Timing**: Control how long vehicles pause at stops

### Strategic Placement
- Place triggers at exhibit viewing points for automatic stops
- Use speed triggers to slow vehicles in areas with better visibility
- Create stop points for photo opportunities or informational moments
- Position triggers before dangerous areas to ensure safe speeds

---

## Creating a Complete Tour System

### Basic Setup
1. **Plan Your Route**: Design a path that showcases your park's best exhibits
2. **Lay Tour Rails**: Place rails following your planned route
3. **Add Triggers**: Position Tour Rail Triggers at key viewing points
4. **Place Vehicle**: Set a Ford Explorer on the rails
5. **Activate Tour Mode**: Use a Wrench to enable automated driving

### Advanced Features
- Create multiple tour routes for different exhibits
- Use triggers to create timed stops with synchronized presentations
- Design figure-eight or loop configurations for continuous tours
- Combine with creature enclosures for optimal viewing experiences

## Trivia
- The Tour Rail system is directly inspired by the self-driving Ford Explorer tour vehicles in *Jurassic Park* (1993), which followed embedded track systems through the park
- Tour Rail Triggers recreate the automated stops and narration points from the film's tour sequence
- The system allows players to recreate the iconic T. rex paddock scene setup with automated vehicle positioning
- Unlike the film where the tour system famously failed, players can create reliable automated tours for their parks
