# Guidebook

The Guidebook is an essential tool for learning about creatures, their genetics, and their needs.  
It provides detailed information on each species, including gene variants and diets.

## Usage

### Reading Information
- Displays detailed data about any discovered species.  
- Shows **gene variants**, **diet** and more.  
- Acts as an in‑game encyclopedia for Jurassic Saga.

### Inspecting Creatures
- Right‑click a dinosaur or creature with the Guidebook to view **real‑time stats**, including:  
  - Hunger  
  - Thirst  
  - Health  
  - Mood or stress (if applicable)  
  - Growth stage  

### Genetic Reference
- Lists all possible **gene variants** for each species.  
- Helps players understand how genetics affect appearance, stats, and behavior.
