# Deinonychus

A medium-sized agile predator from the Cretaceous. It measured around 2 meters tall and was covered in feathers. 
It is the first "raptor"  to be known from a nearly complete skeleton.

## Obtaining
Deinonychus does not spawn naturally. To obtain one, you must:
1. Find ![](@jurassic-saga:textures/item/natural/entity/animal/v2/extinct/deinosuchus/deinosuchus_fossil_remains) [**Deinosuchus Remains**](@jurassic-saga:fossil) or fossils
2. Use the fossil revival process to create an Deinonychus
3. Hatch from an **TBD Egg** type egg
