# Bug Zapper

The Bug Zapper is an automated insect collection device that attracts and captures mosquitoes over time.  
This passive farming tool provides a steady supply of mosquitoes, which can be used as food for insectivorous creatures or other purposes in your park.

---

## Functionality

- **Type**: Passive collection device
- **Produces**: Mosquitoes (item)
- **Placement**: Can be placed anywhere
- **Production Rate**: Generates mosquitoes automatically over time
- **Craftable**: Yes

---

## Usage

1. Craft a Bug Zapper using the recipe below
2. Place the Bug Zapper in any location (indoors or outdoors)
3. Wait for mosquitoes to accumulate
4. Collect mosquitoes from the Bug Zapper periodically
5. Use collected mosquitoes to feed insectivorous creatures or for other purposes

---


---

## Placement Tips

- Can be placed in any location without restrictions
- Multiple Bug Zappers can be used to increase mosquito production
- Works in all biomes and weather conditions
- No power source or special conditions required for operation
- Consider placing near enclosures with insectivorous creatures for convenient feeding

---

## Production

The Bug Zapper passively generates mosquitoes over time. Key details:

- Automatic collection without player intervention
- No fuel or resources required to operate
- Production rate is consistent regardless of placement location
- Check periodically to collect accumulated mosquitoes
- Multiple Bug Zappers increase total mosquito yield

---

## Uses for Mosquitoes

Mosquitoes collected from Bug Zappers can be used for:

- Feeding insectivorous creatures
- Trading or other gameplay purposes
- Stockpiling for future use

---

## Trivia

- The Bug Zapper provides a passive way to farm mosquitoes without manually hunting the flying insects
- Multiple Bug Zappers can create an efficient mosquito farming operation
- The device operates continuously, making it a reliable source of mosquitoes for your park's needs
