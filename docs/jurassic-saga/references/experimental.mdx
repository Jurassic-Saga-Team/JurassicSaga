# Experimental Features

Experimental Features allow you to access **early, in-development content** in Jurassic Saga.  
These features may include new mechanics, new creatures, or systems still being tested.

---

## What They Do
Experimental Features unlock content that is not yet part of the main gameplay.  
This may include:

- New dinosaurs  
- Prototype mechanics  
- Early versions of upcoming systems  
- Balance or behavior experiments  

Because these features are unfinished, they may change in future updates.

---

## How to Enable
To turn on Experimental Features:

1. Open the **Mod's Settings** through the mod button in the main menu
<img width={256} src="https://i.imgur.com/7wG5jJv.png" alt="Mod's Settings"/>

2. Select **JurassicSaga**
<img width={256} src="https://i.imgur.com/8ZUcXEX.png" alt="JurassicSaga"/>

3. Set **Experimental Features** to **True**  
<table style={{borderCollapse: "collapse"}}>
  <tr style={{backgroundColor: "transparent"}}>
  
    <td><img width={256} src="https://i.imgur.com/H6SNMsM.png" alt="False"/></td>
    <td><img width={256} src="https://i.imgur.com/KkKPJKk.png" alt="True"/></td>
  </tr>
</table>

4. **Restart the game** — required for the changes to take effect

---

## Notes
- Experimental content may be unstable or incomplete
- Worlds using these features may behave differently after updates
- You can disable the toggle at any time, but some features may require another restart
