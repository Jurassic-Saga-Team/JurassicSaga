# Installing Addons

Addons allow you to expand Jurassic Saga with extra content created by both the development team and the community  
These addons can introduce new creatures, mechanics, items, or enhancements to your gameplay experience.

---

## Requirements
Before installing any addon, make sure you have:

- **Jurassic Saga** installed
- All **required dependencies** (as listed on the mod's page)

Addons will not function correctly if these requirements are missing.

---

## Where to Download
Jurassic Saga addons can be found on:

- **Modrinth**
- **CurseForge**

Only download addons from trusted sources to avoid corrupted or unsafe files.

---

## How to Install
Installing addons works the same way as installing any other mod:

1. Download the addon file from Modrinth or CurseForge
2. Place the addon `.jar` file into your **mods** folder
3. Ensure it is **alongside JurassicSaga** and its dependencies
4. Launch the game and enjoy the new content

---

## Official Addons
Some addons are created and maintained directly by the **Jurassic Saga Team**  
These addons are fully supported and designed to integrate smoothly with the main mod.

Examples include:

- [JS Expanded (Modrinth)](https://modrinth.com/mod/js-expanded/versions) | [JS Expanded (CurseForge)](https://www.curseforge.com/minecraft/mc-mods/js-expanded)

Official addons will always be clearly labeled on their download pages.

---

## Important Notes
- Addons **not created by the Jurassic Saga team** are **not officially endorsed**
- Any issues, bugs, or questions about third-party addons should be directed to the **addon creator**, not the Jurassic Saga developers
- Some addons may require specific versions of Jurassic Saga to function properly

---

## Tips
- Always read the addon's installation instructions
- Keep backups of your worlds before adding new mods
- Check compatibility between addons to avoid conflicts
