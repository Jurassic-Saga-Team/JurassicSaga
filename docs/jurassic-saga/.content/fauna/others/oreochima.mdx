## Obtaining
Oreochima does not spawn naturally. To obtain one, you must:
1. Enable [Experimental Features]($references/experimental)
2. Find ![](@jurassic-saga:textures/item/natural/entity/animal/v[X]/extinct/oreochima/oreochima_fossil_remains) [**Oreochima Remains**](@jurassic-saga:fossil) or fossils
3. Use the fossil revival process to create a Oreochima
4. Hatch from an **[Egg Type]** type egg
