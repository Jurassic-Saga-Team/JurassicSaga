# DNA Modifier

The DNA Modifier is an advanced genetic engineering machine used to manipulate and combine DNA samples.  
This essential tool allows you to add or remove genes, combine DNA samples to reach 100% completion, and preview creature appearances before creating eggs.

---

## Functionality

- **Type**: DNA manipulation machine
- **Accepts**: DNA samples and spawn eggs
- **Primary Functions**:
  - Combine DNA samples to increase completion percentage
  - Add functional and cosmetic genes to DNA
  - Remove genes from DNA
  - Preview creature appearance and size
- **Requirements**: DNA must reach 100% completion to create an egg

---

## Usage

### Combining DNA Samples
1. Insert two DNA samples of the same species into the input slots
2. The machine combines them to produce a higher percentage DNA sample
3. Repeat until you reach 100% DNA completion
4. 100% DNA is required to create a viable egg

### Adding Genes
1. Insert a DNA sample or spawn egg into the machine
2. Place gene items in the gene slots
3. Add up to multiple functional genes and **one cosmetic gene**
4. Genes are permanently applied to the DNA/creature

### Removing Genes
1. Insert a DNA sample or spawn egg with existing genes
2. Select genes to remove from the interface
3. Removed genes are lost and cannot be recovered

### Preview System
The DNA Modifier features a visual preview showing:
- **Player model** for size comparison
- **Creature model** with current cosmetic gene applied
- **Relative size** between player and creature
- **Current appearance** before finalizing changes

---

## Gene Application

### Functional Genes
Multiple functional genes can be applied to modify stats and abilities:
- Aggressive Instinct, Bone Density, Skin Toughness, etc.
- See the [**Genes**]($references/genes) page for full list

### Cosmetic Genes
**Only one cosmetic gene** can be applied per creature:
- Arid, Pasture, Ocean, Taiga, Alpine, Forest, River, Rainforest, Steppe, Tundra
- Chaos Effect, Legacy (species-specific)
- The preview window shows the selected cosmetic appearance

---

## DNA Completion Process

To create a viable egg, DNA must reach 100% completion:

1. **Extract DNA** from fossils/remains using the [**Genetic Analyzer**](@jurassic-saga:genetic_analyzer)
2. **Combine partial DNA samples** in the DNA Modifier until reaching 100%
3. **Optional: Add genes** to modify the creature's traits or appearance
4. **Create an egg** using 100% DNA in the appropriate machine

For more details, see the [**DNA Modification Guide**]($guides/modifying_dna).

## Trivia
- The DNA Modifier is inspired by the genetic manipulation labs from the Jurassic Park franchise, where scientists altered dinosaur DNA to control breeding and behavior
- The visual preview system allows players to see exactly what their creature will look like before committing to gene modifications
- The one-cosmetic-gene limit encourages strategic choices in creature appearance customization
- The DNA Modifier operates without requiring any fuel or power source
