# Commands

This page provides a comprehensive list of all commands available in Jurassic Saga, including their syntax, permissions, and usage examples.

---

## Overview

Commands in Jurassic Saga allow players and server administrators to:
- Manage creatures and their behavior
- Control experimental features
- Debug and troubleshoot issues
- Adjust gameplay settings
- Access administrative tools

---

## Command Syntax

Commands follow standard Minecraft syntax:
- `/command <required> [optional]`
- Arguments in `<brackets>` are required
- Arguments in `[brackets]` are optional

---

## Available Commands

### General Commands

/gamerule jsDropEggs - true/false - allows animals to lay eggs.
/gamerule jsFasterGrowth - true/false - allows animals to grow faster.
/gamerule jsFeederDrain - true/false - disables consuming the items inside the feeders
/gamerule jsFencesAlwaysOn - true/false - allows fence operate without power.
/gamerule jsMachineSpeed - value - 10-500? (according to coder?)
/gamerule jsMetabolism - true/false - disables or enables food/thirst
/gamerule jsPlantSpread - true/false - allows plants to spread to nearby blocks
