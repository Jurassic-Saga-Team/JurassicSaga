  HOW TO ADD A CREATURE
  1. Find the matching letter section (the "---------- X ----------" comments) and copy any card block inside it (<div ...> down to </div>).

       - the image name (index_images/NAME.webp) and its width/height

       - the **Name** text
  3. Status (optional): for experimental, change the border to "2px solid #DBB600" and add the badge line
     from an existing experimental card. Same for not-added with #e0533d.
  Keep style keys quoted, and keep the [link] lines at column 0 (indenting turns them into code blocks).
