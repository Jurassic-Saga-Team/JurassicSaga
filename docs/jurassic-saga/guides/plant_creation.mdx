# Creating a Plant

With Plant DNA obtained during [Getting Started]($guides/getting_started), you're ready to create a fertilized seed. This is the crucial step toward bringing prehistoric plants back to life.

---

## Requirements

To create a fertilized seed, you'll need:
- A **Plant DNA strand** (must be 100% quality)
- **Seeds or crops**: Wheat Seeds, Beetroot Seeds, Torchflower Seeds, Potato, or Carrot
- A **Syringe (Clean)**

### Supported Seed Types

The following seeds and crops can be fertilized with Plant DNA:
- **Wheat Seeds** — All prehistoric plants
- **Beetroot Seeds** — All prehistoric plants
- **Torchflower Seeds** — All prehistoric plants
- **Potato** — All prehistoric plants
- **Carrot** — All prehistoric plants

<Callout variant="warning">
    **Note:** Melon Seeds and Pumpkin Seeds are currently not supported for fertilization. This may change in future updates.
</Callout>

---

## Process

1. **Clean the Seeds**  
   Place the seeds/crop in a crafting table with a clean syringe  
   **Output:** Unfertilized Seeds

2. **Fertilize the Seeds**  
   Place the Plant DNA (100% quality), the unfertilized seeds, and a clean syringe together in the crafting table  
   **Output:** Fertilized Plant Seeds

3. **Prepare for Cultivation**  
   The fertilized seeds are now ready to be placed in a [Flora Cultivator](@jurassic-saga:flora_cultivator)

---

## Next Steps

You've successfully created fertilized plant seeds! The next stage is placing them in the [Flora Cultivator](@jurassic-saga:flora_cultivator) to grow your prehistoric plants.

---

## Tips

- Always use a clean syringe — dirty ones won't work
- Only Plant DNA can be used to fertilize seeds
- Plant DNA must be exactly 100% quality — partial DNA cannot be used
- Unlike creature eggs which accept varying DNA percentages, plants require complete genetic material
- All supported seed types produce the same fertilized output and can grow any prehistoric plant
- If a seed type doesn't work in crafting, it's not currently supported (like Melon/Pumpkin Seeds)
