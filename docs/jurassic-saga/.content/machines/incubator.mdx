# Incubator

The Incubator is a mid‑stage machine used to safely develop fertilized eggs into hatch‑ready eggs.
It provides a controlled environment that regulates temperature, humidity, and stability, ensuring proper embryo development for prehistoric species.

---

## Information

- Used to cultivate **Fertilized Eggs** into **Hatched Eggs**
- Automatically maintains ideal incubation conditions
- Progress depends on species size and egg type
- Requires no fuel
- Can incubate 5 eggs at a time
- Displays visual animations during operation

---

## Usage

1. Insert a fertilized egg into the input slot  
2. The incubator begins cultivation automatically  
3. Once complete, collect the hatched egg from the output slot  
4. The hatched egg can then be placed in the world to spawn the creature  

### Supported Inputs
- Fertilized "Species" Egg


### Outputs
- Hatched "Species" Egg
